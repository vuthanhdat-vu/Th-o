# Th-o

🎂 **Không gian 3D chúc mừng sinh nhật chị Nguyễn Thạch Thảo**

Trang web 3D tương tác mừng sinh nhật chị Nguyễn Thạch Thảo, gồm:
- Bánh sinh nhật 3D 3 tầng lộng lẫy với nến sáng lung linh
- 20 khung ảnh kỷ niệm rạng rỡ của chị Thạch Thảo trải đều trên 4 không gian 3D (Bánh sinh nhật, Bầu trời phượng hoàng, Đại dương, Đảo mèo)
- Hiệu ứng mưa sao băng và pháo hoa rực rỡ chào mừng tuổi mới
- Nhạc nền du dương và giao diện tinh tế
